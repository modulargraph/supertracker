# Harbor Circuit

Open **Harbor Circuit.supertracker** in SuperTracker and play in Song mode. Keep its adjacent **Harbor Circuit.media** folder with the project. **Harbor Circuit.wav** is the verified 48 kHz, 24-bit stereo export, including a two-second tail.

This original eight-bar piece runs at 116 BPM across four two-bar patterns: Harbor lights (Dm9), Circuit opens (B♭maj7), Glass current (Fmaj9), and Homeward (Cadd9). Six tracks combine a generated kick, a 16-slice percussion kit, a round sampled bass, glass sample chords, Apple DLS piano through Apple Lowpass, and stereo air. It demonstrates sample slices, chords, ratchets, reverse and microtiming step effects, automation lanes, and native delay/reverb sends.

All five bundled samples were synthesized specifically for this demo with a deterministic generator; no user library or third-party sample pack was copied. The Apple piano uses the macOS system DLS sound bank and both Audio Units must be installed. The instrument's internal reverb volume is deliberately set to -120 dB while its normal stereo output mode stays enabled. Spatial effects come from the authored tracker sends.

The collected project and actual opaque plug-in states were saved, opened on a fresh host, and compared against a cold first render using unchanged numerical tolerances. The isolated Apple piano was separately checked for nonzero signal and repeatability. VERIFICATION.json records exact files, levels, comparisons and build provenance. This is offline numerical verification; physical playback and listening quality have not been verified. It does not promise deterministic rendering from every plug-in or preset.

The original internal-reverb preset and rejected diagnostic controls remain preserved outside this release folder. No production host behavior was changed to obtain this demo.
